# Превью

Временное развёртывание (п. 5, 11 спеки). Платформы берутся из строки «Превью» профиля `AGENTS.md`; постоянный сервер выбирает владелец на стадии передачи. Команды GitHub — в `.agents/skills/std-ask/references/github.md`.

## Когда применять

Нужно превью для PR или поставки; превью не поднимается; на контрольной точке требуется дымовой тест.

## Шаги

1. **Платформы.** По профилю: интерфейс, Storybook и сайт документации — Vercel; бэкенд — Render; база данных — Neon (отдельная ветка БД на каждый PR). Другое сочетание — только по профилю.
2. **Переменные окружения.** Настройки — только переменные окружения. Значения хранятся в настройках платформ и секретах GitHub; в репозитории — `.env.example` с фиктивными значениями. Не выводи значения в журналы и PR.
3. **Токены.** Подключение хостингов и MCP-серверов (Vercel, Render, Neon) требует токенов. Выдача токена — решение владельца: если токена нет, оформи вопрос по `.agents/skills/std-ask/SKILL.md` и продолжай задания без превью. Токены сам не создавай и у владельца без вопроса не требуй.
4. **Демо-данные.** Превью заполняется правдоподобными фиктивными данными. Настоящие персональные данные в демо-данные и журналы не попадают; выбери маскирование и генерацию.
5. **Развёртывание на PR.** Превью создаётся для каждого PR; в PR оставь ссылку. Ветка БД Neon закрытого PR удаляется (лимит бесплатного тарифа — 10 веток на проект, Р-28); число одновременно открытых PR с превью держи в пределах лимита.
6. **Дымовой тест.** После каждого развёртывания выполни ключевые сценарии на превью (`/healthz`, `/readyz`, вход, главный сценарий). Render на бесплатном тарифе засыпает после 15 минут простоя: первый запрос может быть долгим, это не ошибка.
7. **Мониторинг.** После первого развёртывания подключи мониторинг доступности и учёт ошибок (Sentry) — каждое подключение нового внешнего сервиса согласуется с владельцем.
8. **Коммерческий проект.** Vercel Hobby разрешён только для некоммерческого использования (Р-28); платформу превью для коммерческого проекта выбирает владелец.

## Результат

Ссылка на работающее превью в PR, пройденный дымовой тест, фиктивные демо-данные.

## Стоп-условия и эскалация

- Нужен токен, новая подписка или новый внешний сервис — вопрос владельцу.
- Окружение не работает после одной повторной попытки — стоп-условие `std-run`.
- Проблема сборки или запуска приложения, а не окружения, — `std-debug`.

## Модель и уровень

Работу выполняет субагент Claude `std-deploy` (Sonnet 5.5, medium). Если ты — субагент `std-deploy`, выполняй сам. Параметры вызова Codex — `.agents/codex-runs.json`, запись `std-deploy`.
