# Передача проекта

Стадия 6 (п. 10 спеки). Полноту комплекта проверяет контрольная точка 5 (`.agents/skills/std-gate/SKILL.md`). Документы пишутся по `.agents/skills/std-docs/SKILL.md`. Команды GitHub — в `.agents/skills/std-ask/references/github.md`.

## Когда применять

Все поставки приняты, подготовлена контрольная точка 5.

## Шаги

1. **Перечень.** Составь по таблице комплекта п. 10 перечень документов, обязательных для проекта по его профилю: общее описание; заметки к выпуску; протокол приёмки; руководство пользователя, частые вопросы и ошибки (интерфейс); руководство администратора (роли); руководство по развёртыванию, справочник настроек, руководство по эксплуатации; README; `ARCHITECTURE.md`, `decisions.md`, глоссарий; справочник API (API); справочник БД (БД); видеоинструкции (по решению владельца); стратегия тестирования; модель безопасности; технический долг и ограничения; CHANGELOG, SBOM, перечень лицензий.
2. **Полнота.** Для каждой позиции проверь: файл есть, актуален, не пуст, соответствует коду; нужные схемы из таблицы схем п. 10 есть, собираются и читаемы; термины из глоссария; деловой стиль. Недостающее оформи заданиями (`std-plan`, `std-docs`).
3. **Автоматически формируемое:** справочники настроек, API и БД, протокол приёмки, скриншоты, SBOM (syft), перечень лицензий, CHANGELOG (release-please) пересобери и убедись, что расхождений нет.
4. **Развёртывание.** Руководство по развёртыванию проверь на чистой среде: `docker compose up` из `deploy/`, домен и HTTPS, первый администратор, обновление, откат; схема развёртывания приложена.
5. **Выгрузка.** Сайт документации (Starlight) собран; документы выгружены в DOCX и PDF через pandoc, схемы — в SVG. Выгрузка прикладывается к релизу и в репозиторий не коммитится.
6. **Передача.** Оформи сообщение для владельца: что передаётся, где лежит, какие ограничения и технический долг остаются, как выбрать постоянную площадку (вопрос владельцу, `std-ask`).

## Результат

Полный комплект документов и схем, SBOM и перечень лицензий, выгрузка DOCX/PDF, сообщение о передаче.

## Стоп-условия и эскалация

- Документ противоречит коду или требованиям — замечание контрольной точки 5, а не правка «по ощущениям».
- Выбор постоянной площадки и подключение новых сервисов — решение владельца.
- Настоящие персональные данные и секреты в документы и выгрузки не попадают.

## Модель и уровень

Работу выполняет субагент Claude `std-handoff` (Sonnet 5.5, high). Если ты — субагент `std-handoff`, выполняй сам. Параметры вызова Codex — `.agents/codex-runs.json`, запись `std-handoff`.
