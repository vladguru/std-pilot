# Техническое задание

Статус: черновик.

После согласования владельцем статус заменяется на «согласовано ДД.ММ.ГГГГ». Объёмное ТЗ допускается размещать в `docs/`; тогда этот файл служит указателем на него.

## Требования

Каждое требование имеет идентификатор ТР-NN. Идентификатор не меняется и не используется повторно.

| ID | Требование | Приоритет |
|---|---|---|
| ТР-01 | Образец: система хранит перечень клиентов с контактными данными | обязательно |

## Критерии приёмки

Каждый критерий имеет идентификатор AC-NN, ссылку на требование и форму «дано / когда / тогда». Для каждого согласованного критерия пишется автоматический тест с идентификатором критерия в имени или комментарии.

### AC-01. Образец: добавление клиента

Требование: ТР-01.

- **Дано:** пользователь с правом добавления клиентов открыл перечень клиентов.
- **Когда:** пользователь заполняет обязательные поля и сохраняет карточку клиента.
- **Тогда:** клиент появляется в перечне, а пользователь видит сообщение об успешном сохранении.
