# Заметки к выпуску

Раздел содержит заметки к каждой версии системы: изменения, которые заметят пользователи. Заметки пишутся для владельца и пользователей деловым языком, без технических подробностей.

| Документ | Файл | Содержание |
|---|---|---|
| Заметки к выпуску | `vN.md` (по одному файлу на версию, например `v1.md`) | Новые функции, изменения в работе, исправленные ошибки, известные ограничения |

Технический перечень изменений (CHANGELOG) формируется автоматически из сообщений коммитов и в этот раздел не входит.
