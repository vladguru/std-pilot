# Документы для разработчиков

Раздел содержит документы для разработчиков, которые принимают и сопровождают систему. Устройство системы описано в `ARCHITECTURE.md`, решения — в `docs/decisions.md`.

| Документ | Файл | Содержание | Включение |
|---|---|---|---|
| Стратегия тестирования | `testing.md` | Устройство тестов, запуск, покрытие | всегда |
| Модель безопасности | `security.md` | Модель угроз, матрица «роль × действие», перечень персональных данных и сроки хранения, схема потоков данных | всегда |
| Технический долг и ограничения | `tech-debt.md` | Упрощения и их причины, недоделанное, рекомендации по развитию | всегда |
| Справочник API* | `api.md` | Описание API из схемы OpenAPI | API |
| Справочник БД* | `database.md` | Таблицы и ER-диаграмма из базы данных | база данных |
| Перечень лицензий* | `licenses.md` | Лицензии зависимостей; запрещены GPL, AGPL и некоммерческие | всегда (к передаче) |
| SBOM | `sbom.json` | Перечень компонентов, формируется syft (SPDX JSON; строки-маркера в JSON нет) | всегда (к передаче) |

\* Формируется автоматически. Такой файл начинается строкой «Файл формируется автоматически, не редактировать»; CI проверяет, что он совпадает с результатом повторного формирования.
