# Документы для пользователей

Раздел содержит документы для пользователей и администраторов системы.

| Документ | Файл | Содержание | Включение |
|---|---|---|---|
| Руководство пользователя | `user-guide.md` | Работа по ролям и задачам, пошагово; карта экранов; скриншоты формируются e2e-тестами при каждом выпуске | интерфейс |
| Руководство администратора | `admin-guide.md` | Пользователи, роли, права, настройки | роли пользователей |
| Частые вопросы и ошибки | `faq.md` | Действия при типовых ситуациях; тексты ошибок совпадают с интерфейсом | интерфейс |

Колонка «Включение» указывает параметр профиля в `AGENTS.md`, при котором документ обязателен.
