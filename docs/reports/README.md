# Отчёты

Раздел содержит отчёты контрольных точек и протоколы приёмки.

| Документ | Файл | Содержание |
|---|---|---|
| Отчёт контрольной точки | `gate-N.md` (N — номер контрольной точки) | Проверяемый объём, замечания по уровням «критично / важно / незначительно», принятые решения, итоги петли обучения |
| Протокол приёмки* | `acceptance-vN.md` (vN — версия) | Требование → AC → тест → результат → дата |

\* Формируется автоматически из трассировки AC → тест. Такой файл начинается строкой «Файл формируется автоматически, не редактировать»; CI проверяет, что он совпадает с результатом повторного формирования.
