# Документы для эксплуатации

Раздел содержит документы для специалистов, которые разворачивают систему и обеспечивают её работу.

| Документ | Файл | Содержание |
|---|---|---|
| Руководство по развёртыванию | `deployment.md` | Требования к серверу, установка через `docker compose`, домен и HTTPS, первый администратор, обновление, откат, схема развёртывания |
| Справочник настроек* | `configuration.md` | Все переменные окружения: назначение, значение по умолчанию, обязательность |
| Руководство по эксплуатации | `operations.md` | Мониторинг, действия при сбоях, резервное копирование и восстановление |

\* Формируется автоматически из кода. Такой файл начинается строкой «Файл формируется автоматически, не редактировать»; CI проверяет, что он совпадает с результатом повторного формирования.
