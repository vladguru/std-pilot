## Запуск за 5 минут

1. Установить [mise](https://mise.jdx.dev) — он устанавливает закреплённые версии языков и инструментов.
2. Выполнить `mise install`.
3. Скопировать `.env.example` в `.env`. Значения в образце фиктивные и подходят для локального запуска.
4. Выполнить `make dev`.
5. Открыть адрес, который выведет команда.

Проверка перед открытием PR — `make ci`.
