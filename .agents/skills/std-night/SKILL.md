# Ночная смена

Работа агентов в отсутствие владельца (п. 5 спеки). Расписание, ночной бюджет и время сводки берутся из профиля `AGENTS.md` («Ночная смена», «Ночной бюджет»). Команды GitHub — в `.agents/skills/std-ask/references/github.md`.

## Когда применять

Сессию запускает расписание: запланированная облачная задача Claude Code или automation Codex. Пример расписания: 22:00 — первая сессия, 03:00 — вторая после обновления окна лимитов, 07:30 — утренняя сводка.

## Шаги

1. **Проверки.** Нет открытого issue `пауза` (иначе смена не начинается). Ночной бюджет профиля не исчерпан; остаток отслеживай по `std-progress`. Если данных о расходе нет (в новой облачной среде их часто нет), бери не более трёх заданий за ночную сессию (Р-54).
2. **Отбор.** Бери только задания с согласованными AC, закрытыми зависимостями и без открытых вопросов. Задания в бизнес-областях профиля («Бизнес-области «неясность = стоп»») оставляй на дневное время.
3. **Захват.** Исполнитель (`std-task`) захватывает задание до начала работы — назначением и комментарием «Захвачено:»: так дневная и ночная сессии не берут одно задание.
4. **Работа.** Запусти `std-run` (`.agents/skills/std-run/SKILL.md`) по отобранным заданиям. Вопрос без умолчания, возникший ночью, останавливает только своё задание (метка `стоп`, вопрос по `std-ask`); смена переходит к следующему независимому заданию.
5. **Завершение.** Смена завершается, когда исчерпан ночной бюджет, нет подходящих заданий или поставлена `пауза`.
6. **Утренняя сводка.** В заданное время запусти `std-progress`: что сделано, что ожидает владельца, расход токенов. Сводка публикуется комментарием в issue сводок; владелец получает уведомление GitHub.

## Результат

Выполненные задания, остановленные задания с вопросами, утренняя сводка в issue сводок.

## Стоп-условия и эскалация

Ночью запрещено:

- сливать PR с меткой `на-согласовании`;
- изменять ограничители (CI, пороги, правила линтера, защиту веток, `AGENTS.md`);
- подключать внешние сервисы и запрашивать токены;
- превышать ночной бюджет.

Остальные стоп-условия — как у `std-run`. Если подходящих заданий нет, не придумывай работу: опубликуй сводку «заданий для ночной смены нет».

Настройка расписания выполняется однократно при подключении проекта к GitHub (`sync --github`, план 5); в самом проекте скилл расписание не меняет.

## Модель и уровень

Смена ведётся в основной сессии на лёгкой модели (Sonnet 5.5, medium; Codex — GPT-6.1 Sol, medium). Субагент `std-night` задан для единообразия: если эта инструкция передана тебе субагентом `std-night`, выполняй сам шаги без вызова субагентов и сообщи, что запускать смену нужно из основной сессии. Параметры вызова Codex — `.agents/codex-runs.json`, запись `std-night`.
