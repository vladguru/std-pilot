# Сетевые адреса облачных сред

Документ принадлежит стандарту (обновляется `sync`). Полный доступ в сеть в облачных средах не включается: токены действующие, и внедрённая в данные инструкция не должна иметь возможности их передать (спека, п. 5). Среда Claude Code работает в режиме «Доверенные» (Trusted); если нужного адреса там нет, среда переводится в режим «Custom» со списком из этого документа. Переключение — настройка в веб-интерфейсе; её выполняет агент через браузер с разрешения владельца, одним вопросом на пакет действий (Р-45).

Статусы: **подтверждено** — проверено в облачной сессии (план 2); **не проверено** — адрес следует из документации инструмента, наличие в списке «Доверенные» не проверялось.

## Установка среды (`.agents/cloud-setup.sh`)

| Адреса | Для чего | Статус |
|---|---|---|
| `registry.npmjs.org` | Пакеты npm: Playwright, agent-browser, серверы MCP (`npx`) | подтверждено (Д-2) |
| `pypi.org`, `files.pythonhosted.org` | Пакеты Python (`uvx`, `uv`): Serena, postgres-mcp | подтверждено (Д-2) |
| `mise.run`, `mise.jdx.dev` | Установка mise и сведения о версиях | не проверено |
| `github.com`, `api.github.com`, `objects.githubusercontent.com`, `release-assets.githubusercontent.com`, `raw.githubusercontent.com` | Исполняемые файлы инструментов (mise, uv, Vale, gitleaks и др.) | не проверено |
| `nodejs.org` | Node 24 по `.mise.toml` (в облаке Claude по умолчанию Node 22) | не проверено |
| `go.dev`, `dl.google.com`, `proxy.golang.org`, `sum.golang.org` | Go и модули Go | не проверено |
| `cdn.playwright.dev`, `playwright.download.prss.microsoft.com`, `storage.googleapis.com` | Браузеры Playwright и agent-browser | не проверено |
| `archive.ubuntu.com`, `security.ubuntu.com`, `deb.debian.org`, `security.debian.org` | Пакеты apt (PostgreSQL, системные библиотеки браузеров) | не проверено |

## Серверы MCP (после выдачи токенов владельцем)

| Адрес | Для чего | Статус |
|---|---|---|
| `api.githubcopilot.com` | GitHub MCP | закрыт в «Доверенных» (Р-38), нужен «Custom» |
| `mcp.vercel.com` | Vercel MCP | закрыт в «Доверенных» (Р-38), нужен «Custom» |
| `mcp.render.com` | Render MCP | закрыт в «Доверенных» (Р-38), нужен «Custom» |
| `mcp.neon.tech` | Neon MCP | закрыт в «Доверенных» (Р-38), нужен «Custom» |
| `context7.com`, `mcp.context7.com` | Документация библиотек (Context7) | не проверено |

Токены выдаёт владелец (спека, п. 2); без токена соответствующий сервер не подключается, а адрес в список не добавляется.

## Как пользоваться

1. Начните с режима «Доверенные». Выполните `bash .agents/cloud-setup.sh` и прочитайте сводку: не выполненные шаги названы в конце, подробности — в `/tmp/std-cloud-setup.log`.
2. Если шаг не выполнен из-за сети, добавьте в режим «Custom» только адреса этого шага из таблицы и повторите запуск.
3. Адреса серверов MCP добавляются только после выдачи токена владельцем.
